# 8051 Seven Segment Display

## Project Overview
This project demonstrates interfacing a seven-segment display with the 8051 microcontroller to display numeric digits.

## Components Used
- 8051 Microcontroller
- Seven Segment Display
- Resistors
- Connecting Wires
- Power Supply

## Working Principle
The 8051 microcontroller sends digital signals to the seven-segment display. The corresponding segments glow to display the required numbers.

## Applications
- Digital Counters
- Digital Clocks
- Electronic Display Systems

## Learning Outcome
Learned microcontroller interfacing and seven-segment display programming.
